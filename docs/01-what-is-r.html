1  What Is R?

R is a free and open-source computing programming language built for working with data and statistics. Natively, it has no windows or buttons of its own — it simply reads commands and does the math, statistics, or data-wrangling you ask for. However, with the use o RStudio or Posit Cloud, you can interact with R through a graphical interface in a very friendly manner.

1.1 R, RStudio, and Posit Cloud

These three names get used almost interchangeably by beginners, but they are three different things:

Name What it actually is
R The language itself and the engine that runs it. No graphical interface.
RStudio A free application (“IDE”) that wraps around R: a console, a script editor, a file browser, and a plot viewer in one window.
Posit Cloud The exact same RStudio, but running inside a web browser. Nothing to install. Covered fully in Chapter 8.

You write R code the same way regardless of which of the three you’re looking at. The rest of this guide uses RStudio’s and Posit Cloud’s layout as the reference point.

1.2 The console

Every screenshot and example in this guide refers to the console — the pane where you type one command, press Enter, and R answers immediately.

print("Hello, R!")
[1] "Hello, R!"

The [1] at the start of the output is not part of your answer — it’s R’s way of numbering the elements of the result. For a single value it will always read [1]; you’ll see higher numbers later when a result contains many values.

2 + 2
[1] 4
TipA useful habit

Read code left to right, the same way you’d read a sentence: x <- 5 reads as “x gets 5.” The arrow always points toward where the value is being stored. R is a language oriented to objects - every value you create you store in a variable called object by using the assignment operator <-. You can also use =, but this is not a good practice in R coding.

1.3 The pipe operator |>

The pipe operator is one of the most useful tools of R coding. Think it about putting something in a box. Let’s see an example with a mock dataframe called df. The glimpse() function is to see what is in the dataframe.

Option 1. Without the pipe operator

glimpse(df)

Option 2. With the pipe operator

df |>
  glimpse()

It works like the pipe |> puts the object df inside the function glimpse(). It is very useful for sequential codes such as:

df |>
  filter(baseline == 0) |>
  select(var1, var2, var2, var3) |>
  count()

Within this sequence of code, it means you first filtered your dataframe only for those in which the variable baseline == 0. Among them, selected the variables var1, var2, var3 and applied the function count(), to check the total N among them.

1.4 What is a data.frame, an object and a vector?

In the R environment, you will deal with these three main concepts and utils and as soon as you have intimicity with them, quick will be your learning.

1.4.1 A data.frame

A data frame, in R environment called as data.frame, is a matrix of columns and lines storing utility to provide data. Is in a data.frame that your variables of interest will be stored, and the observations as well. For example:

Lets have 10 patients observed at the same time and you collected the variables age, bmi and upc (ultraprocessed foods uptake) of them at the very same time. You will have an ID for each patient as well. Your data.frame looks like this:

1.4.2 vectors

Interestingly, to create this data frame, we gathered vectors, which are a sequence of characters, numbers, logical operators, combination between characters and numbers, dates. First, a vector called n was created as follows: n <- seq(1:10). This means a sequence from 1 to 10 was created so far. As an another example, the upc variable was derivated from a Normal distribution using the rnorm function as follows: upc <- rnorm(n, 4000, 560), where n is the sample size, 4000 the mean and 560 the standard deviation. The same rationale was made for all other variables in this simulated data.frame and then all variables were combined after.

1.4.3 objects

Finally, all vectors and including the data frame were stored in objects. Objects in R are a cornerstone part of the coding. Being a programming language oriented to objects, everything you code in R you store in an object whatever you want to call it. We will fastforward an example you will see in the section R as a calculator.

We will operate basic arithmetic operations by using letters instead of numbers.

Let’s a <- 5, b <- 6 and c <- 7.

a <- 5
b <- 6
c <- 7

## Summation of a + b 

### Of course, 5 + 6 = 11, but let's see as stored in the objects a and b

a + b

The same is valid for everything in R. You can call a function, a data frame, whatever you want by an object and change it.


df <- read_csv("Documents/nutritionexample.csv")

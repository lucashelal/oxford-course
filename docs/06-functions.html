ages <- c(21, 34, 19, 45, 30, 28, 52)

6.2 Working with Dataframes: The NutriHeart Study

A single vector is fine for one measurement, but real research almost never stops at one measurement. A real study measures several things about the same person — their age, their diet, their body mass index. R stores this kind of data in a dataframe: a table where every row is one participant and every column is one variable.

To practice this, we will use the same diet_habits.csv dataset from Chapter 3 — a small, simulated dataset modeled on a real type of study in nutritional epidemiology.

6.2.1 The study context

Imagine a research team wants to understand how eating patterns relate to cardiometabolic health — that is, health related to the heart and metabolism. They design a study called the NutriHeart Study.

Research question: Among adults, is the type of diet a person follows (Mediterranean, Western, Vegetarian, or Vegan) associated with cardiometabolic markers such as body mass index (BMI) and daily caloric intake?

To answer this, the team recruits 40 adult participants. Each participant answers a short questionnaire. This is a cross-sectional study: everyone is measured once, at a single point in time, which lets the researchers describe patterns in the population but not prove that diet causes the outcomes.

Every variable the team collects has a reason for being there. Before opening the file, it helps to know what we expect to find and why:

# Variable What it means Type
1 participant_id A unique number identifying each participant Identifier
2 age Age in completed years at enrollment Continuous
3 diet_type The dominant diet pattern the participant reports following Categorical
4 bmi Body Mass Index (kg/m²), a common marker of nutritional status Continuous
5 daily_calories Estimated average daily caloric intake (kcal) Continuous

Notice that these 5 variables cover the two basic data types you’ll meet constantly in nutritional epidemiology: numbers that can take any value (continuous), and labels that fall into groups (categorical).

6.2.2 Opening the dataset

We already imported this exact file once, in Chapter 3. Do it again here, either by typing the code yourself:

nutriheart_data <- read.csv("data/diet_habits.csv")

or by clicking through File → Import Dataset → From Text (readr), exactly as shown in Figure 3.2 and Figure 3.3 back in Chapter 3.

Tip

Whichever route you use, name the resulting object nutriheart_data — that’s the name the rest of this chapter (and Chapter 7) assumes.

6.3 Descriptive statistics by variable type

Different variable types answer different questions, so they need different summary functions. nutriheart_data has two families of variables — continuous and categorical — and we’ll summarize each one appropriately, using $ to pull out a single column (e.g. nutriheart_data$age means “the age column inside nutriheart_data”).

6.3.1 Continuous variables (age, bmi, daily_calories)

For continuous variables, we want to know the center of the data and how spread out it is.

mean(nutriheart_data$bmi)      # the average BMI
[1] 25.9075
median(nutriheart_data$bmi)    # the middle BMI, if all values were sorted
[1] 25.85
sd(nutriheart_data$bmi)        # standard deviation: typical distance from the mean
[1] 3.496987
range(nutriheart_data$bmi)     # smallest and largest BMI values, as one vector
[1] 18.0 33.2
summary(nutriheart_data$bmi)   # all of the above, in one call
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
  18.00   23.23   25.85   25.91   28.38   33.20

summary() is often the fastest first step: with one function call it returns the minimum, the 1st quartile (the value below which 25% of the data falls), the median, the mean, the 3rd quartile, and the maximum — a compact picture of the whole distribution.

6.3.2 Categorical variables (diet_type)

For categorical variables, “average” makes no sense — instead, we want counts and proportions per group.

table(nutriheart_data$diet_type)                              # how many participants per diet

Mediterranean         Vegan    Vegetarian       Western 
           14             5             6            15 
round(prop.table(table(nutriheart_data$diet_type)) * 100, 1)  # same thing, as percentages

Mediterranean         Vegan    Vegetarian       Western 
         35.0          12.5          15.0          37.5
  • table(x) counts how many times each unique category appears in x.
  • prop.table(t) takes a table of counts and converts every count into a proportion of the total (values between 0 and 1). Multiplying by 100 and wrapping in round(..., 1) turns those proportions into readable percentages with one decimal place.

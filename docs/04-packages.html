4  Installing Packages

R ships with a solid toolkit built in, but its real strength is packages — free add-ons written by the community that add extra functions. Think of them as apps for R.

4.1 Step 1 — Install it, once

install.packages("tidyverse")

This downloads the package from CRAN, R’s official package repository. You only need to run this once per computer (or once per Posit Cloud project).

4.2 Step 2 — Load it, every session

library(tidyverse)

Installing puts a tool in the toolbox; library() takes it out and puts it on the table. Run this line every time you restart R and want to use that package.

WarningQuotes on, quotes off

Notice the quotation marks appear in install.packages("tidyverse") but disappear in library(tidyverse). This inconsistency trips up almost everyone at least once — it isn’t a mistake on your part.

4.3 Packages worth knowing early

Package What it’s for
tidyverse A bundle of packages for wrangling and plotting data
readxl Reading Excel files
rmarkdown / quarto Turning your code into reports, like this guide
descr Descriptive statistics and frequency tables
lubridate Transform text in dates and manipulate date formats as well
janitor To clean variables artifacts mainly
ggplot2 Make beautiful plots to visualize your data
here Use relative paths instead of absolute paths
pacman Install, read and open automatically a bunch of packages
gt Make presentable tables
NotePosit Cloud

Popular packages are often pre-installed there — try library(...) first before reaching for install.packages(). Details in Chapter 8.
